Импорт серийных номеров

Самый быстрый способ: выделите строки в таблице, нажмите Ctrl+C и вставьте в поле ниже (Ctrl+V). Можно и загрузить файл .xlsx или .csv. Если серийный номер уже есть в базе, данные по нему будут обновлены.

Если вставляете строки без заголовка — колонки по порядку:

  1. Серийный номер
  2. Дата покупки
  3. Модель (имя часов)
  4. Имя покупателя
  5. Телефон (можно оставить пустым)

Пример:
BRNV190292  09.11.2026  Сұңқар Про  Диас  87017748080
Цвет и срок гарантии подставятся автоматически по модели.

Если вставляете вместе с заголовком или загружаете файл — названия колонок:

  • Серийный номер
  • ФИО владельца
  • Номер владельца
  • Имя часов
  • Дата покупки
  • Цвет
  • Статус
